# Profile (example)

This file is sent to Gemini on every run that has changes to judge.
It is what turns "the page changed" into "ignore this" or "apply today."
Replace it with your own. It is plain text, not code.

## Who this is for

An undergraduate sophomore in the US recruiting for consulting and finance
internships. Does not need visa sponsorship. Eligible for sophomore and
early-identification programs, not for junior-only or full-time analyst roles.

## What counts as a meaningful change

- A relevant program opening applications, posting a deadline, or changing
  eligibility.
- Anything that changes what this person should do this week.

## What does NOT count

- Non-US roles.
- Full-time, associate, or graduating-class roles meant for older students.
- Layout, wording, or cosmetic changes that do not change what is offered.
